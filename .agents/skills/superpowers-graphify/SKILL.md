# Superpowers + Graphify

1. Sebelum membaca file satu per satu, jalankan:
   graphify query "<pertanyaan tentang kode>"
2. Sebelum menulis kode, brainstorm dulu: jelaskan pendekatan
   dan tanyakan hal yang belum jelas.
3. Tulis rencana singkat, tunggu persetujuan, lalu kerjakan bertahap.
4. Setelah mengubah kode, jalankan `graphify update .`
   supaya peta tetap mutakhir.
